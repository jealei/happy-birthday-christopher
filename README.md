# Happy birthday, Christopher

A very dramatic countdown to midnight (Norway time) on 12 November 2026.

Live: https://jealei.github.io/happy-birthday-christopher/

## Test it

- `?t=15` – the countdown ends 15 seconds from now.
- `?party` – go straight to the party.

Run locally: `python3 -m http.server 5173`, then open http://localhost:5173/?t=15
